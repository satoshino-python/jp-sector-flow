読み方の注意

  • 売買代金は買いと売りの合計で、純流入ではありません。方向は価格とセットで見てください。
  • 集計対象は大型株中心です。不動産・小売・サービスなど中小型が多い業種は精度が落ちます。
  • 先物・オプションSQ、指数リバランス、決算期は売買代金が歪みます。
  • 純フローは外国人投資家の週次売買(JPX)などで裏取りしてください。
